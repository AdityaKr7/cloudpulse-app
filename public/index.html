STEP 1

Launch an Ubuntu 24.04 LTS EC2 Instance

AWS Console

Go to AWS Management Console → EC2 → Launch Instance.

  • Name: CloudPulse-Server
  • AMI: Ubuntu Server 24.04 LTS (HVM) (Free tier eligible)
  • Instance Type: t2.micro (or t3.micro)
  • Key Pair: Select or create a new key pair (e.g. my-ec2-key.pem), download it to your local machine.
  • Network / Security Group: Check: Allow SSH (Port 22) Allow HTTP (Port 80) Allow HTTPS (Port 443)
STEP 2

Connect to Your EC2 Instance via SSH

Local Terminal

Open your local terminal in the folder where your .pem file was downloaded. Restrict key permissions and connect:

Terminal (SSH) 
# 1. Set strict read-only permissions for your private key
chmod 400 my-ec2-key.pem

# 2. SSH into your Ubuntu instance as the default 'ubuntu' user
ssh -i my-ec2-key.pem ubuntu@13.233.54.120
STEP 3

Install Node.js LTS, Git, and PM2 on Ubuntu

EC2 Terminal

Once inside your EC2 terminal, update system packages and install Node.js 20/22 LTS and PM2 globally:

Ubuntu Shell 
# Update package index
sudo apt update && sudo apt upgrade -y

# Install Node.js LTS (v20) via NodeSource
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs git build-essential

# Verify versions
node -v && npm -v

# Install PM2 globally (Process Manager for production)
sudo npm install -g pm2
STEP 4

Deploy App & Start with PM2 (Daemon)

EC2 Terminal

Place your app code in /var/www/cloudpulse-app, install dependencies, and launch it with PM2 so it stays running in the background and restarts automatically if the server reboots!

Ubuntu Shell 
# Create application directory
sudo mkdir -p /var/www/cloudpulse-app
sudo chown -R ubuntu:ubuntu /var/www/cloudpulse-app
cd /var/www/cloudpulse-app

# Clone your repository (or copy files via scp/git)
# git clone  .

# Install dependencies
npm install --omit=dev

# Start app using PM2 ecosystem configuration
pm2 start ecosystem.config.cjs --env production

# Configure PM2 to auto-start on server reboots
pm2 startup
# (Run the sudo env PATH... command that PM2 outputs if prompted)
pm2 save

# Verify running processes
pm2 status
STEP 5

Configure Nginx Reverse Proxy (Port 80 → Port 5000)

Nginx

Nginx listens on public port 80 and transparently forwards requests to your Express app running locally on port 5000.

Ubuntu Shell 
# Install Nginx
sudo apt install -y nginx

# Copy the pre-configured Nginx file to sites-available
sudo cp /var/www/cloudpulse-app/nginx/cloudpulse.conf /etc/nginx/sites-available/cloudpulse

# Update server_name with your EC2 Public IP or Domain
sudo sed -i 's/YOUR_EC2_PUBLIC_IP_OR_DOMAIN/13.233.54.120/g' /etc/nginx/sites-available/cloudpulse

# Enable the site and remove default site
sudo ln -sf /etc/nginx/sites-available/cloudpulse /etc/nginx/sites-enabled/
sudo rm -f /etc/nginx/sites-enabled/default

# Test Nginx syntax and reload
sudo nginx -t && sudo systemctl restart nginx

# Verify Nginx status
sudo systemctl status nginx --no-pager
STEP 6

Configure UFW Firewall & Optional Free SSL (Certbot)

Security

Lock down Ubuntu's firewall to only allow necessary ports (OpenSSH and Nginx Full) and install a free SSL certificate with Let's Encrypt:

Ubuntu Shell 
# Configure UFW (Uncomplicated Firewall)
sudo ufw allow OpenSSH
sudo ufw allow 'Nginx Full'
sudo ufw --force enable
sudo ufw status

# Optional: Add Free HTTPS / SSL with Certbot (Requires a custom domain pointing to your EC2 IP)
sudo apt install -y certbot python3-certbot-nginx
# Run certbot (Replace cloudpulse.example.com with your actual domain):
# sudo certbot --nginx -d cloudpulse.example.com

Quick Reference

Essential EC2 & PM2 Commands Cheatsheet

PM2 Management

  • pm2 list - View running apps & CPU/RAM
  • pm2 logs - Stream live application logs
  • pm2 restart all - Restart application
  • pm2 monit - Interactive visual terminal monitor

Nginx Operations

  • sudo nginx -t - Test config syntax
  • sudo systemctl reload nginx - Zero-downtime reload
  • sudo tail -f /var/log/nginx/error.log - Error logs
  • sudo tail -f /var/log/nginx/access.log - Access logs

Ubuntu & System

  • htop - Live CPU & RAM monitor
  • df -h - Check available disk space
  • free -m - Check RAM in Megabytes
  • sudo journalctl -u nginx -e - Nginx system logs
